# IRCTC Bookings Analytics Dashboard

An interactive Power BI dashboard analysing Indian Railways (IRCTC) ticket bookings.

 ## Watch the demo video - https://drive.google.com/file/d/1rt3CP1oFOFLUsWu9O55qq6aIte6Mv-a7/view?usp=sharing

## Features
- KPI cards: Total Sales, Average Rating, Avg Ticket Value, Rating Count, Total Bookings
- Monthly, daily and weekly sales trends
- Sales by food preference (Veg / Non-Veg)
- Top 5 cities by sales
- State-wise map and table of sales, rating and bookings
- Slicers for Month, Class and Train

## Dataset
IRCTC_Bookings_2026.csv has 6,000 bookings from Jan to Sep 2026.
The data is synthetic and created for this project.

## Tools
Power BI Desktop, DAX, Excel/CSV

## How to open
Download IRCTC_Dashboard.pbix and open it in Power BI Desktop.
